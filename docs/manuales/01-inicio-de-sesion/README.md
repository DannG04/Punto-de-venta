# Inicio de sesión y pantalla principal

Manual de usuario · Punto de Venta

> **Antes de empezar:** las imágenes de este manual muestran una tienda de ejemplo, *Abarrotes La Esperanza*, con datos ficticios. En tu negocio verás tus propios productos, empleados y clientes.

## ¿Para qué sirve?

Para entrar al sistema con tu usuario, moverte entre las secciones del punto de venta y salir de forma segura al terminar tu turno. Todo lo que hagas mientras tengas la sesión abierta (ventas, ajustes, compras…) queda registrado a tu nombre.

## Iniciar sesión

Al abrir el programa aparece la ventana de inicio de sesión.

![Ventana de inicio de sesión](img/01_inicio_sesion.png)

1. **Nombre de usuario:** elige tu usuario en la lista. Solo aparecen los empleados activos.
2. **Contraseña:** escribe tu contraseña. Acepta solo letras y números, hasta 10 caracteres.
3. **Ojo:** muestra u oculta lo que escribiste en la contraseña.
4. **Iniciar Sesión:** entra al sistema. También puedes pulsar **Enter** desde el campo de contraseña.

Pasos:

1. Elige tu nombre de usuario.
2. Escribe tu contraseña.
3. Pulsa **Iniciar Sesión** o la tecla **Enter**.
4. Aparece un mensaje de bienvenida con tu nombre. Pulsa **Aceptar**.

![Mensaje de bienvenida](img/05_bienvenida.png)

### Ver la contraseña mientras la escribes

Si no estás seguro de lo que escribiste, pulsa el botón del **ojo**: la contraseña se muestra en texto normal. Vuelve a pulsarlo para ocultarla.

![Contraseña visible](img/04_mostrar_contrasena.png)

### Si algo sale mal

**No escribiste la contraseña.** Debajo del campo aparece el aviso *"Debe ingresar una contraseña"*.

![Aviso de contraseña vacía](img/02_sin_contrasena.png)

**La contraseña no es correcta.** Aparece una ventana de error que dice *"Contraseña incorrecta"*. Pulsa **Aceptar** y vuelve a intentarlo.

![Error de contraseña incorrecta](img/03_contrasena_incorrecta.png)

> **Nota:** si olvidaste tu contraseña, pide al gerente que la revise en **Administración › Empleados**.

## La pantalla principal

Después de entrar verás la pantalla principal. Es el punto de partida para todo lo demás.

![Pantalla principal](img/06_pantalla_principal.png)

1. **Menú:** las secciones del punto de venta. Haz clic en una para abrirla.
2. **Tu foto de perfil:** pasa el mouse sobre ella para ver tus datos.
3. **Cerrar sesión:** sale del sistema (ver más abajo).
4. **Servidor móvil:** permite consultar y registrar productos desde un celular. Tiene su propio manual.
5. **Fecha y hora** actuales.
6. **Aviso de actualización:** aparece solo cuando hay una versión nueva del programa (solo lo ve el gerente).

### Ver tus datos

Pasa el mouse sobre tu foto de perfil para ver tu nombre, CURP, puesto y teléfono.

![Datos del usuario](img/07_datos_usuario.png)

## El menú

| Opción | Para qué sirve |
|---|---|
| **Inicio** | Regresa a la pantalla principal. |
| **Inventario** | Consultar productos, agregarlos, actualizarlos y ajustar su existencia. |
| **Ventas** | Cobrar a los clientes. |
| **Apartados** | Registrar productos apartados con anticipo y abonos. |
| **Clientes** | Dar de alta y consultar clientes. |
| **Devoluciones** | Registrar productos que el cliente regresa. |
| **Cotizaciones** | Preparar presupuestos y convertirlos en venta. |
| **Reportes** | Gastos, otras ganancias y reportes del negocio. |
| **Administración** | Opciones del gerente (compras, empleados, kardex, etc.). |

Cada opción tiene su propio manual.

### Menú Reportes

Al hacer clic en **Reportes** se despliegan sus opciones: **Gastos**, **Ganancias**, **Bal. General** (balance general), **Est. Resultados** (estado de resultados) y **Rep. Diario** (reporte diario).

![Menú Reportes](img/08_menu_reportes.png)

### Menú Administración (solo gerentes)

El menú **Administración** solo aparece si entras con un usuario de puesto **gerente**. Contiene **Compras**, **Empleados**, **Proveedores**, **Categorías**, **Reg. Ventas** (registro de ventas y corte de caja), **Kardex**, **Empresa** y **Actualizaciones**.

![Menú Administración](img/09_menu_administracion.png)

Cuando hay una actualización disponible, el menú muestra un punto (**Administración •**) y la opción **Actualizaciones** indica la versión nueva.

Si entras con un usuario de puesto **vendedor**, el menú termina en **Reportes**:

![Menú de un vendedor](img/11_menu_vendedor.png)

## Cerrar sesión

Cuando termines tu turno, cierra tu sesión para que nadie más registre operaciones a tu nombre.

1. Ve a **Inicio**.
2. Pulsa **Cerrar sesión**.
3. Aparece el mensaje *"Hasta luego"*. Pulsa **Aceptar**.

![Mensaje al cerrar sesión](img/10_hasta_luego.png)

El programa regresa a la ventana de inicio de sesión. Si el **servidor móvil** estaba encendido, se apaga al cerrar la sesión.

## Corte de caja automático

Si el programa sigue abierto a las **11:59 p. m.**, se abre automáticamente la ventana del **corte de caja** con las ventas del día. Consulta el manual de **Registro de ventas** para saber cómo leerla.

## Consejos

- Cada persona debe usar **su propio usuario**: las ventas, compras y ajustes de inventario guardan quién los hizo.
- Cierra la sesión si vas a dejar la computadora sola.
- Si no aparece tu usuario en la lista, es posible que esté dado de baja; consulta con el gerente.
