# Actualizaciones

Manual de usuario · Punto de Venta

> **Antes de empezar:** las imágenes de este manual muestran una tienda de ejemplo, *Abarrotes La Esperanza*, con datos ficticios.

## ¿Para qué sirve?

Permite instalar las versiones nuevas del punto de venta sin reinstalar el programa. Las actualizaciones traen mejoras y correcciones, y actualizan la base de datos cuando hace falta, **sin borrar tu información**.

Esta sección está en **Administración** y solo la usa el **gerente**. Necesita conexión a internet.

## Cómo saber si hay una versión nueva

Cuando el gerente inicia sesión, el programa revisa si hay una actualización (y vuelve a revisar cada 6 horas). Si la hay:

- El menú muestra un punto: **Administración •**.
- La opción dice **Actualizaciones (versión disponible)**.
- En la barra de abajo aparece *"Hay una actualización disponible"*.

![Aviso en el menú](img/01_menu_con_aviso.png)

## Cómo entrar

En el menú superior haz clic en **Administración** y elige **Actualizaciones**.

![Pantalla de Actualizaciones](img/02_pantalla_actualizaciones.png)

1. **Versión instalada** en esta computadora.
2. **Versión disponible** para instalar.
3. **Estado** de la búsqueda.
4. **Buscar ahora:** revisa en este momento si hay una versión nueva.
5. **Actualizar ahora:** descarga e instala la versión disponible.

## Instalar una actualización

1. Pulsa **Buscar ahora**. Si hay una versión nueva, se muestra su número y la lista de **novedades**.

![Versión disponible](img/03_version_disponible.png)

2. Asegúrate de que **no haya una venta en curso** (el carrito de Ventas debe estar vacío).
3. Pulsa **Actualizar ahora** y confirma con **Sí**.

![Confirmar la actualización](img/04_confirmar_actualizacion.png)

4. El programa se cierra y se actualiza. Windows pedirá permiso de administrador: **acéptalo** (si no aparece, búscalo parpadeando en la barra de tareas).
5. Al terminar, el punto de venta se abre solo con la versión nueva.

## Mensajes que pueden aparecer

| Mensaje | Qué hacer |
|---|---|
| *Tienes la versión más reciente* | No hay nada que instalar. |
| *No se pudo consultar. Revisa la conexión a internet.* | Revisa el internet y vuelve a pulsar **Buscar ahora**. |
| *Hay una venta en curso; termínela o vacíe el carrito.* | Termina o cancela la venta antes de actualizar. |

## Consejos

- Actualiza **al cerrar el día** o cuando no haya clientes: el programa se cierra unos minutos.
- Antes de una actualización importante, conviene tener un respaldo de la base de datos.
