# Otras ganancias

Manual de usuario · Punto de Venta

> **Antes de empezar:** las imágenes de este manual muestran una tienda de ejemplo, *Abarrotes La Esperanza*, con datos ficticios.

## ¿Para qué sirve?

Registra el dinero que entra al negocio **sin ser una venta de productos**: comisiones por recargas de tiempo aire o pago de servicios, venta de cartón para reciclaje, etc. Estas ganancias se suman en el **Estado de resultados**.

El sistema también agrega aquí, automáticamente, lo que la tienda conserva cuando un **apartado se cancela o se anula**.

## Cómo entrar

En el menú superior haz clic en **Reportes** y elige **Ganancias**.

![Pantalla de Otras Ganancias](img/01_pantalla.png)

1. **Lista de ganancias:** folio, descripción, monto y fecha.
2. **Descripción** de la ganancia.
3. **Monto** en pesos.
4. **Agregar:** registra la ganancia con la fecha de hoy.
5. **Actualizar:** corrige la ganancia seleccionada.
6. **Eliminar:** borra la ganancia seleccionada.

## Registrar una ganancia

1. Escribe la **descripción**, por ejemplo *"Comisión por venta de tiempo aire (semana)"*.
2. Escribe el **monto**.
3. Pulsa **Agregar**.

![Registrar una ganancia](img/03_agregar.png)

La ganancia aparece en la lista con la fecha de hoy:

![Ganancia registrada](img/04_registrado.png)

Si dejas algún campo vacío, aparece el aviso *"Llene todos los campos"*:

![Campos vacíos](img/02_campos_vacios.png)

## Corregir una ganancia

1. Selecciona la ganancia en la lista.
2. Pulsa **Actualizar**.
3. Corrige la descripción o el monto y pulsa **Actualizar**.

![Actualizar una ganancia](img/05_actualizar.png)

## Eliminar una ganancia

Selecciona la ganancia y pulsa **Eliminar**. Se borra en cuanto pulsas el botón, sin pedir confirmación.

![Eliminar una ganancia](img/06_eliminar.png)

Las ganancias que genera el sistema por **cancelación** o **anulación de apartados** no se pueden eliminar:

![Ganancia de apartado](img/07_no_se_puede_eliminar.png)

## Consejos

- Registra las comisiones con la misma descripción cada semana para comparar fácilmente.
- No registres aquí las ventas de productos: esas se hacen en **Ventas**.
